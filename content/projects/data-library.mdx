    <h2>Data Processing</h2>
    <p>Data pipelines are a black box. Users upload files, wait, and hope. The status card makes the process visible: it surfaces each step — upload, index, retriever setup — in real time, so users can track progress, spot failures early, and know the moment their knowledge base is ready for agents. The status framework allows any data source pipeline to plug into it so users gets consistent experience across all data source type.</p>
